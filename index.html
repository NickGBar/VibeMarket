Для ИИ-агентов

Подключите VibeMarket к Claude Code

Агент найдёт бесплатную замену платной программе, скачает установщик под ваш компьютер и сверит SHA-256. Устанавливаете вы сами.

claude mcp add vibemarket -- npx -y github:NickGBar/VibeMarket

В Claude Desktop, Cursor и других клиентах — та же команда npx в настройках MCP.

    В каталоге только проекты с открытым исходным кодом. Всё бесплатно: без рекламы, баннеров, поп-апов и трекеров. Эта страница не загружает ни одного внешнего скрипта, шрифта или пикселя.
